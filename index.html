Privacy-Preserving Elderly Fall Detection

Team
4 members, B.Tech final-year project
My part
Literature survey, Hampel-filter mathematical model, Python DSP algorithm development
Stack
Python, Matplotlib, Telegram Bot API. Phase 2: ESP32, ESP32-S3, HC-SR501 PIR sensor

Problem

Falls can cause serious injury, especially when a person cannot call for help. Camera systems expose images of a private space, and wearables only work if the person is wearing and has charged them. This project tests whether WiFi Channel State Information (CSI), a measure of how a wireless signal changes as people move through a room, can detect a fall with neither.

How it works

  1. TransmitAn ESP32 sends UDP packets to set up a WiFi signal in the monitored room.
  2. ReceiveAn ESP32-S3 collects CSI from the packets. A PIR sensor adds a presence cue.
  3. FilterAmplitude is computed from the I and Q samples, cleaned with a 15-frame Hampel filter, then reduced to a variance value.
  4. DecideA finite state machine looks for an impact followed by stillness.
  5. AlertA local buzzer sounds and a message goes out through the Telegram Bot API.

The detection rule

  • Variance above 5.0 marks a candidate impact.
  • The system then watches for 3 seconds. Variance must fall below 1.5 and the PIR cue must confirm presence. Otherwise it returns to idle.
  • A confirmed fall starts the buzzer and a 60-second recovery countdown, then the alert is sent.
  • The Hampel filter replaces any value more than 3 median absolute deviations from the window median.

Design decisions

  • Ambient sensing, so there is no camera and nothing to wear.
  • Two checks before an alert. An impact alone is only a candidate, so a loud movement does not raise an alarm.
  • A transparent filter and threshold pipeline instead of a pre-trained classifier, so each step can be explained and tuned.
  • A planning target of under ₹1,500 for the basic prototype parts.
  • The report states that thresholds must be calibrated for each room and that CSI is not independent of room conditions.

Research

My literature survey covers five papers across CSI deep learning, CSI movement detection, mmWave radar, wearable sensors and first-person vision. It points to the gap this design targets: an understandable detector that does not need a trained model.

Solar-Powered Aquaculture Monitor

Team
4 members
Stack
Arduino UNO, ESP32, SX1278 LoRa, DS18B20, dissolved oxygen sensor, cloud dashboard

What it does

A solar-powered node that monitors water conditions for aquaculture in real time. It measures temperature and dissolved oxygen, sends readings wirelessly over LoRa with a range of about 2 km, and pushes them to a cloud platform that shows live graphs for monitoring and trend analysis.

What I worked on

  • Integrated the DS18B20 temperature sensor and the dissolved oxygen sensor for continuous monitoring.
  • Set up the wireless link with the SX1278 LoRa module and sent data to the cloud dashboard.
  • Added LCD-based alerts at the node.
  • Worked on the power chain: solar panel, TP4056 charging module and MT3608 boost converter, with SPI communication between parts.
